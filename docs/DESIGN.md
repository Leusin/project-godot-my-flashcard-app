# 제품과 데이터 규칙

Markdown으로 빠르게 카드를 작성하고, 버튼과 스와이프로 복습하는 개인용 앱이다. 카드 내용과 다음 행동을 우선하며, 오답 횟수는 핵심 학습 정보로 유지한다.

현재 범위는 로컬 덱 관리와 복습이다. 계정·클라우드 동기화·AI 생성·SRS는 제공하지 않는다. 코드 구조는 [CODE_GUIDE](CODE_GUIDE.md)를 참고한다.

## 화면별 역할

| 화면 | 주요 동작 |
| --- | --- |
| 덱 목록 | 덱 선택, 헤더 ＋로 생성·파일 가져오기·클립보드 가져오기, ⋮에서 이름순·최근 학습순과 설정 |
| 학습 준비 | 덱 전체 완료 현황, 학습 범위·순서 선택, 시작·이어하기, 카드 관리, 덱 메뉴 |
| 카드 목록 | 질문·답 검색, 카드 추가, 기본순·질문순·오답 많은 순 정렬, 카드 상세·수정·삭제 |
| 카드 상세 | 탭으로 앞뒤 전환, 메뉴로 수정·삭제. 결과에서 열었으면 결과로 복귀 |
| 카드 편집 | 질문·답·오답 횟수·상태 수정, 명시적으로 저장. 미저장 변경을 버릴 때 확인 |
| 학습 | 카드 탭으로 답 확인, 앞뒷면 모두 판정 버튼 사용, 스와이프·방향키 지원 |
| 결과 | 판정별 카드 확인, ‘다시 볼게요’ 카드만 재학습, 학습 준비로 복귀 |
| 설정 | ZIP 백업·복원, 모바일 진동, 개인정보 처리방침, 버전 정보 |

덱 메뉴는 복제·이름 변경·Markdown 내보내기·삭제를 제공한다. 덱과 카드 목록은 정렬 기준을 선택하며 직접 드래그 재정렬하지 않는다. 카드 목록의 정렬은 Markdown 순서나 학습 순서를 바꾸지 않는다.

검색은 질문과 답의 대소문자를 구분하지 않는 부분 일치다. 검색 중 카드 추가 버튼은 숨기고, 검색을 지우면 복원한다.

## 학습 규칙

- 범위는 전체·미완료·오답 카드다. 미완료는 MASTERED가 아닌 카드, 오답은 누적 오답 횟수가 1 이상인 카드다.
- 순서는 원본 순서 또는 무작위다. 준비 화면의 완료 비율은 선택 범위가 아닌 덱 전체 MASTERED 비율이다.
- 유효한 이어하기 기록이 있으면 남은 카드와 순서를 복원한다. 준비 화면에서 설정만 바꾸어도 기존 기록은 유지한다.
- 이어하기 기록이 있을 때 새로 시작은 확인을 거쳐 진행 위치를 교체한다. 카드별 오답 횟수와 상태는 초기화하지 않는다.

| 입력 | 기록과 이동 |
| --- | --- |
| 다시 볼게요 / 왼쪽 | 오답 +1, LEARNING으로 변경, 다음 카드 |
| 기억나요 / 오른쪽 | MASTERED로 변경, 다음 카드. 누적 오답은 유지 |
| 위쪽 | 기록 변경 없이 건너뛰기 |
| 아래쪽 | 현재 세션의 이전 카드로 이동. 이미 저장한 판정을 되돌리지는 않음 |
| 카드 탭 | 앞뒷면 전환 |

판정한 카드는 같은 회차에 자동 재삽입하지 않는다. 이전으로 돌아가 다시 판정하면 새 판정이 적용되며, ‘다시 볼게요’는 오답을 다시 증가시킨다. 결과의 재학습 대상은 이번 회차에서 ‘다시 볼게요’로 판정한 카드다.

앞면과 뒷면 모두 ‘다시 볼게요 / 기억나요’를 표시한다. 마지막 카드 전까지 빈 뒷장을 보이고, 다음 카드는 뒷장 위치에서 앞으로 온다. 아래로 넘겨 이전 카드로 돌아갈 때는 위에서 들어온다. 전환 중 판정 입력은 잠근다.

## Markdown과 기록

문서 하나가 덱 하나다. 줄 시작의 `# `가 질문이며 다음 질문 전까지가 답이다.

```markdown
# Apple
사과
# Red
빨간색
```

- 빈 답과 여러 줄 답을 허용한다. 빈 질문은 카드로 만들지 않으며, 첫 질문 앞의 내용은 무시한다.
- 답에 줄 시작 `# `를 넣으면 새 카드가 되므로 편집기에서는 저장을 거부한다.
- 가져오기는 앱 내부로 복사한다. 가져오기·내보내기는 원문을 보존하고, 앱에서 카드를 편집하면 writer 형식으로 다시 저장한다.
- 진행도 JSON은 덱별 **질문 문자열**을 키로 쓴다. 같은 질문의 카드들은 오답 횟수와 상태를 공유한다.
- 질문을 앱에서 바꾸면 저장 시 기록을 옮긴다. 같은 옛 질문이 남아 있으면 그 기록은 유지한다. 최종 새 질문의 오답·상태는 편집기에 표시한 값으로 저장하므로, 기존 질문과 이름이 겹치면 그 질문의 공유 기록도 바뀐다.
- 앱 밖에서 질문을 바꾼 경우 이전 기록을 자동 연결하지 않는다. 중복 질문 카드 하나를 삭제해도 같은 질문이 남아 있으면 기록을 유지한다.
- NEW·LEARNING·MASTERED와 오답 횟수는 편집기에서도 수정할 수 있다.

이어하기는 덱 내용 해시와 남은 원본 카드 인덱스를 검증한다. 일반 카드 편집·삭제는 기존 이어하기를 무효화하며, 학습 중 현재 카드를 편집할 때는 진행 중 세션과 이어하기를 함께 갱신한다.

ZIP 백업에는 덱·진행도·이어하기·설정이 들어간다. 복원은 확인 후 현재 데이터를 백업 내용으로 교체한다.

## 공통 UI 기준

- 카드 목록의 오답 표식은 질문 옆의 연한 회색이다. 0은 숨기고, 1~5는 막대, 5 초과는 숫자만 표시한다.
- 답 위치는 카드 중심을 기준으로 유지한다. 긴 답은 왼쪽 정렬과 스크롤을 사용한다.
- 컨텍스트 메뉴는 공통 씬과 굵은 테두리를 공유한다. 열린 메뉴도 창 크기 변화에 맞춰 기준 버튼을 따라간다.
- 마우스 호버로 버튼 외형을 바꾸지 않는다. 눌림과 키보드 포커스 반응은 유지한다.
- 현재 화면 기준은 세로 720×1280, `canvas_items / expand`다. PC 창 종횡비 고정은 구현되어 있지 않다.

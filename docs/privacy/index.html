개인정보처리방침

My Simple Flash Card · 시행일 2026년 8월 24일

My Simple Flash Card는 개인정보나 기기 데이터를 개발자 또는 제3자에게 수집, 전송, 공유하지 않습니다.

1. 처리하는 정보

앱은 회원가입, 광고, 분석 도구를 사용하지 않으며 인터넷 서버를 운영하지 않습니다. 앱이 사용하는 다음 정보는 사용자의 기기 안에서만 처리됩니다.

  • 사용자가 만들거나 가져온 Markdown 카드 덱
  • 카드별 학습 기록, 상태, 즐겨찾기와 이어서 학습 정보
  • 마지막 덱과 학습 순서 등의 앱 설정

2. 파일과 클립보드

앱은 사용자가 직접 가져오기, 내보내기 또는 클립보드에서 만들기를 선택한 경우에만 해당 파일이나 클립보드 내용을 처리합니다. 이 내용은 앱 기능을 수행하기 위해 기기에서 로컬로 처리되며 개발자나 제3자에게 전송되지 않습니다.

3. 정보 공유와 외부 서비스

앱은 사용자 정보를 판매하거나 제3자와 공유하지 않습니다. 광고 SDK, 분석 SDK 또는 추적 도구를 포함하지 않습니다. Google Play 자체에서 처리하는 정보에는 Google의 개인정보처리방침이 적용됩니다.

4. 보관과 삭제

앱 내부 데이터는 사용자가 앱에서 삭제하거나 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거할 때까지 기기에 보관됩니다. 사용자가 앱 밖으로 내보낸 Markdown 파일은 사용자가 직접 삭제할 때까지 선택한 위치에 남을 수 있습니다.

5. 보안

앱 내부 데이터는 Android의 앱 전용 저장 공간에 보관됩니다. 앱은 사용자 데이터를 외부 서버로 전송하지 않으므로 전송 과정에서 처리되는 사용자 데이터가 없습니다.

6. 아동의 개인정보

앱은 아동을 포함한 사용자의 개인정보를 의도적으로 수집하지 않습니다.

7. 방침 변경

앱의 데이터 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 함께 갱신합니다.

8. 문의

개인정보 관련 문의는 My Simple Flash Card 공개 문의 페이지에 남길 수 있습니다. 공개 게시판이므로 문의 내용에 개인정보나 민감한 정보를 포함하지 마세요.

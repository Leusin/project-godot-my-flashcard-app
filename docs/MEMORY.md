# 프로젝트 방향

Markdown 문서 하나로 카드를 작성하고 PC와 Android에서 같은 덱 형식으로 복습하는 개인 프로젝트다. 작성과 편집에 드는 수고를 줄이고, 버튼과 스와이프의 조작감을 다듬는 데 집중한다.

Godot의 씬·signal·입력·Tween과 Android 배포를 익히며, 작은 씬을 에디터에서 직접 조정할 수 있는 구조를 지향한다. 미래의 확장보다 지금 사용할 수 있는 작은 기능을 먼저 완성한다.

- 현재 제품·데이터 규칙: [DESIGN](DESIGN.md)
- 코드 책임과 수정 위치: [CODE_GUIDE](CODE_GUIDE.md)
- 구현 규칙: [CONVENTIONS](CONVENTIONS.md)
- 재발 방지를 위한 시행착오: [DEVLOG](DEVLOG.md)

이 문서에는 장기적인 동기와 우선순위만 남긴다. 현재 기능이나 변경 이력은 중복 기록하지 않는다.
